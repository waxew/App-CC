# CACTUS Collection — Android

اپلیکیشن اندروید CACTUS Collection برای مشاهده پوشاک، سفارش چاپ DTF اختصاصی، انتخاب طرح‌های آماده و ثبت سفارش تکی یا عمده.

## نسخه فعلی

**v1.0.1 — versionCode 2**

این نسخه یک به‌روزرسانی پایدار برای v1.0.0 است و با همان Application ID و همان کلید امضای Release ساخته می‌شود تا روی نسخه قبلی نصب شود و داده‌ها و تنظیمات محلی کاربر حفظ شوند.

## امکانات فعلی

- اسپلش اختصاصی با هویت CACTUS Collection
- ثبت‌نام با شماره موبایل و امکان ادامه به‌صورت مهمان
- فرم تکمیل و ویرایش مشخصات کاربر با ذخیره محلی اطلاعات
- صفحه خانه با دسته‌های تیشرت، هودی، شلوار، چاپ اختصاصی، فروش عمده و طرح‌های آماده
- باشگاه مشتریان و ساختار اولیه امتیاز، سطح کاربر، پست، لایک، نظر و چالش طراحی
- منوی همبرگری RTL از سمت راست
- سفارش‌های من، پروفایل، تنظیمات و اعلان‌ها
- معرفی به دوستان، درباره ما و تماس با پشتیبانی
- صفحه «درباره نرم‌افزار» کوتاه و کاربرمحور، بدون نمایش نام بسته یا جزئیات فنی و همراه نمایش خودکار شماره نسخه
- مدیریت صحیح دکمه Back: صفحات داخلی به صفحه قبلی برمی‌گردند و کاربر مستقیماً از برنامه خارج نمی‌شود
- ساختار نسخه‌بندی پایدار برای آپدیت نسخه‌های بعدی

## تغییرات v1.0.1

- اضافه شدن Back Stack مرکزی برای رفع خروج ناخواسته با دکمه برگشت اندروید
- حفظ رفتار طبیعی Back در صفحه اصلی
- تأیید وجود منوی همبرگری و Drawer سمت راست
- ساده‌سازی بخش درباره نرم‌افزار و نمایش `BuildConfig.VERSION_NAME`
- اضافه شدن کامنت‌های توضیحی فارسی داخل فایل‌های Kotlin، Gradle و منابع اندروید
- اضافه شدن Gradle Wrapper برای باز کردن و Build راحت‌تر پروژه روی لپ‌تاپ
- اجرای Android Lint در CI قبل از تحویل نسخه پابلیش
- بررسی صحت امضای APK با `apksigner`
- تولید ZIP کامل سورس همراه `info.txt` و فایل keystore برای نگهداری قابلیت آپدیت

## ساخت نسخه Release روی لپ‌تاپ

پس از باز کردن پروژه در Android Studio، Gradle Sync را انجام دهید. همچنین از ترمینال ریشه پروژه می‌توان اجرا کرد:

```bash
./gradlew assembleRelease
```

خروجی Release در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/release/app-release.apk
```

## ساخت و انتشار خودکار

Workflow موجود در `.github/workflows/android.yml` موارد زیر را انجام می‌دهد:

1. آماده‌سازی نسخه و مستندسازی سورس
2. ساخت Gradle Wrapper در صورت نبودن
3. Build امضاشده Release
4. اجرای Android Lint
5. بررسی گواهی امضای APK
6. تولید فایل پابلیش `CACTUS-Collection-v1.0.1.apk`
7. تولید ZIP سورس همراه `info.txt`

## نکته حیاتی درباره آپدیت‌ها

برای اینکه نسخه‌های آینده روی نسخه نصب‌شده کاربر نصب شوند، **Application ID و کلید امضا نباید تغییر کنند**. فایل ZIP تحویلی شامل `info.txt` و keystore لازم برای ساخت نسخه‌های سازگار بعدی است. این فایل‌ها باید در محل امن و دارای نسخه پشتیبان نگهداری شوند.
