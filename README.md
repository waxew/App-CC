# CACTUS Collection — Android

نسخه 1.0.0 اپلیکیشن اندروید CACTUS Collection برای سفارش چاپ DTF و پوشاک اختصاصی.

## امکانات نسخه 1.0.0

- اسپلش اختصاصی با لوگوی CACTUS Collection
- ثبت‌نام با شماره موبایل با گزینه «بعداً ثبت نام می‌کنم» و «رد کردن» تا زمان اتصال سامانه پیامک
- فرم تکمیل مشخصات کاربر و ذخیره محلی اطلاعات
- صفحه خانه با طراحی فانتزی/مدرن و دسته‌های تیشرت، هودی، شلوار، چاپ اختصاصی، فروش عمده و طرح‌های آماده
- باشگاه مشتریان با امتیاز، سطح کاربر، پست‌ها، لایک، نظر و چالش‌های طراحی آزمایشی
- منوی همبرگری سمت راست
- سفارش‌های من، حساب کاربری، تنظیمات و اعلان‌ها
- معرفی به دوستان، درباره ما، تماس با ما و درباره نرم‌افزار
- ساختار نسخه‌بندی پایدار برای نصب نسخه‌های بعد روی همین نسخه

## تکنولوژی

Kotlin + Jetpack Compose + Material 3

- Application ID: `com.asteam.cactuscollection`
- Version code: `1`
- Version name: `1.0.0`
- Minimum Android: Android 7.0 (API 24)

## Build

GitHub Actions فایل Release APK امضاشده را با workflow موجود در `.github/workflows/android.yml` تولید می‌کند.

> نکته امنیتی: کلید امضای نسخه اولیه برای حفظ قابلیت آپدیت در ریپوی خصوصی پروژه نگهداری شده است. قبل از عمومی کردن ریپو، کلید و رمز آن باید به GitHub Secrets منتقل شوند.
